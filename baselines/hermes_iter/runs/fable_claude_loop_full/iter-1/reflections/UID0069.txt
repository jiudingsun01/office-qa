I recorded the generalizable lesson by patching the existing `tb-math-transform-wrappers` skill (rather than creating a duplicate), since it already housed the parametric-VaR recipe.

What went wrong and what the skill now captures:

- **Methodology**: "Expected shortfall at 95% confidence using the historical portfolio return approach" on N retrieved level values (here, 10 January yields) means: compute simple percent returns between consecutive observations (N−1 returns), take the worst ceil(0.05 × n) returns as the tail — which with ≤20 returns is just the single worst return — and ES is the mean of that tail. The correct answer −18.51% corresponds to the Jan 1995 → Jan 1996 drop in New Aa yields (≈8.86 → 7.22).
- **Sign convention**: report ES as the negative return itself (e.g. −18.51), not a positive loss figure and not a parametric (μ/σ/z) quantity — my answer of 6.14 failed on both counts.
- **Disambiguation**: added a note contrasting "historical approach" (use empirical returns directly) with the previously documented parametric "loss exceeded with X% probability" recipe, so future agents pick the right one.
- **Retrieval reminder**: yearly fixed-month yields across a decade must be stitched from ~one bulletin per year, and the two cells producing the extreme return deserve a double-check since the entire answer hinges on that one pair.

I also updated the skill's frontmatter description to include "expected shortfall (historical approach)" so the skill triggers on this phrasing.
