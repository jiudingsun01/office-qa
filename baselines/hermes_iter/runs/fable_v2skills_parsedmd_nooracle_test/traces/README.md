# Full agent trajectories — Fable 5 + gpt-5.5 (v2) skills, parsed-md, NO-ORACLE (28 test Q)

One `<uid>.md` per question: the complete Hermes session for **claude-fable-5**
running on the `officeqa-iter-v2` profile (gpt-5.5-evolved skills) over the
held-out 28-question test split, in the **non-oracle** setting on the **parsed-md**
corpus — the agent is NOT told which bulletin/section; it greps the parsed-Markdown
corpus to retrieve.

- Run result: **23/28 = 0.821** (see `../summary.json`, `../per_row.jsonl`) — the
  strongest no-oracle test result in this repo, and ~2x faster than the PDF
  no-oracle runs (median ~135 s/q, no timeouts) because retrieval is `grep` over
  text rather than repeated `pdftotext`.
- Generated by `../../../dump_traces.py` with `--model claude-fable-5
  --prompt-contains final_parsed_db_augmented` (the v2 profile's session dir is
  shared across gpt-5.5 / Opus / Fable runs, so model + corpus-marker filters
  disambiguate this run's 28 sessions).
- Base64 page images stripped to a placeholder (Fable on parsed-md rarely
  rasterizes, so traces are small); verbatim raw sessions in `../traces_raw.tar.gz`
  (gitignored, ~1.4 MB).
- Each file header lists the source session, predicted vs gold, and score.

> Note: scored with this repo's `reward.py`; the official upstream scorer
> normalizes whitespace, which would flip a couple of list-format misses upward.
> No-oracle test prompts carry no gold answer and no reflection pass runs, so the
> traces don't expose the answer key.
