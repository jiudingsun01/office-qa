KEY DEFINITIONS FOR FINANCIAL/STATISTICAL TERMS — read the question literally and implement the standard finance definition, not a shortcut:

- "Portfolio/historical returns": when a question asks about RETURNS derived from a series of values (yields, totals, etc.), first convert the level series into a return series. Period return is typically the percent change between consecutive observations: r_t = (x_t / x_{t-1} − 1) * 100 (in percent). This usually produces NEGATIVE numbers and percent-scale magnitudes — do NOT confuse a raw yield level (e.g., 6.14) with a return.

- "Expected Shortfall (ES) / Conditional VaR at X% confidence (historical approach)": compute it on the RETURN series, not the raw levels. ES at 95% = the average of the returns in the worst (1 − 0.95) = 5% tail of the distribution. With small samples, do not silently collapse to a single point estimate without checking the intended method; the expected output is a percent value (often reported with a % sign and negative, e.g., -18.51%). Match the exact rounding and whether a % sign / sign is expected.

- "Pearson correlation coefficient": use the sample Pearson r between the two paired monthly series for the specified calendar year. Verify every paired value against the source before computing.

- "Geometric annual rate of change" over N years between two period values: (end/start)^(1/N) − 1.

- "Fisher Ideal symmetric growth rate" between two values x1 (start) and x2 (end): g = 2*(x2 − x1)/(x2 + x1). CRITICAL — PAY ATTENTION TO THE OUTPUT SCALE/UNITS. This formula yields a DECIMAL FRACTION (e.g., for x1=13.61, x2=12.15: g = 2*(12.15−13.61)/(12.15+13.61) = −0.1134). Unless the question explicitly asks for a percentage, report the raw decimal value (−0.113), NOT the percent-multiplied form (−11.335). When in doubt about whether a growth/change rate should be expressed as a decimal or a percentage, re-read the question: only multiply by 100 if it says "in percent" or asks for a "%" answer. The same caution applies to any ratio/growth/rate-of-change quantity — do not multiply by 100 by default.

- "Sample standard deviation": use ddof=1 (n−1 denominator). "How many standard deviations off the average" = z-score = (value − mean) / sample_sd, keeping sign.

- General rule: if the requested quantity is a transformation (return, growth rate, log-change, deviation), apply the transformation BEFORE the statistic.
