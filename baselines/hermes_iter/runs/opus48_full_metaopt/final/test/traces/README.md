# Full agent trajectories — Opus 4.8 final test (28 held-out questions)

One `<uid>.md` per question: the complete Hermes session for the **evolved**
`officeqa-iter-opus48` agent (claude-opus-4-8) on the held-out test split of
`opus48_full_metaopt` — every reasoning step, tool call, and tool result, in order.

- Generated by `../../../../dump_traces.py` from the Hermes session files (which
  live in the profile dir, outside the repo).
- **Base64 page images** (from `vision_analyze`) are replaced with a
  `[BASE64 IMAGE STRIPPED: N chars]` placeholder to keep these readable/committable.
- The verbatim sessions (including the images) are in `../traces_raw.tar.gz`
  (gitignored — ~12 MB).
- Each file's header lists the source session, the `predicted` vs `gold` answer,
  and the score.

> Gating note: tool-result blocks reproduce small excerpts of the gated Treasury
> Bulletin corpus (the table rows the agent read). The test **prompts** contain no
> gold answers, and test has no reflection pass, so these traces don't expose the
> answer key — but see `../../../../EXPERIMENTS.md` §9 before publishing.
